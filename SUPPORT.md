# Support

Start with the [documentation site](https://nix-forge.github.io/nix-config-framework/),
the [README](README.md), and the compatibility guide. Check whether a plain
module import is enough before adding the framework to a consumer.

For a bug or a reproducible framework problem, [open an issue](https://github.com/nix-forge/nix-config-framework/issues/new).
Include the commit or input revision, NixOS, nix-darwin, or Home Manager
version, the target layout, relevant options, and the smallest useful log
excerpt. Remove secrets and private paths before posting.

Use [SECURITY.md](SECURITY.md) for suspected vulnerabilities. Do not disclose
security-sensitive details in a public issue.

This project does not provide managed system configurations or private
deployment support. A minimal consumer fixture is the most useful support
request.
