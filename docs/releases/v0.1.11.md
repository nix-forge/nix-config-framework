# nix-config-framework v0.1.11

Historical source release for the signed [v0.1.11][source] tag. This note was
written during the September 2026 release evidence backfill; it was not part
of the original tagged tree.

## Changelog

### Functional changes

Moved target-specific home arguments to each home module when Home Manager is
embedded in a host. Added integration fixtures for host-attached homes.

### Security changes

No security-specific change was recorded.

### Consumer impact and migration

Embedded Home Manager consumers with per-home argument hooks should update if
host-level arguments shadowed those values.
