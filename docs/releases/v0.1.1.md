# nix-config-framework v0.1.1

Historical source release for the signed [v0.1.1](https://github.com/nix-forge/nix-config-framework/tree/v0.1.1) tag. This note was written during the September 2026 release evidence backfill; it was not part of the original tagged tree.

## Changelog

### Functional changes

Added `nixConfigFramework.extraSpecialArgsFor`, a hook receiving the target kind and target specification. Generated host and standalone home configurations now receive the hook result.

### Security changes

No security-specific change was recorded.

### Consumer impact and migration

Consumers that need target-specific helpers can use the new option; the existing project-wide argument option remains available.
