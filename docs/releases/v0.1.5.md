# nix-config-framework v0.1.5

Historical source release for the signed [v0.1.5](https://github.com/nix-forge/nix-config-framework/tree/v0.1.5) tag. This note was written during the September 2026 release evidence backfill; it was not part of the original tagged tree.

## Changelog

### Functional changes

A directory containing `default.nix` now selects that module as its aggregate. Child files remain separately selectable instead of being imported automatically through the directory selector.

### Security changes

No security-specific change was recorded.

### Consumer impact and migration

Review selectors for directories with `default.nix`: selecting the directory no longer imports every child.
