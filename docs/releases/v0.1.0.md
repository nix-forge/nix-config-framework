# nix-config-framework v0.1.0

Historical source release for the signed [v0.1.0][source] tag. This note was
written during the September 2026 release evidence backfill; it was not part
of the original tagged tree.

## Changelog

### Functional changes

Introduced flake-parts integration, path-based module discovery, NixOS and
nix-darwin host outputs, standalone Home Manager outputs, shared module
envelopes, target local modules, and project-level special arguments.

### Security changes

No security-specific change was recorded for this initial version.

### Consumer impact and migration

First public version; consumers should follow their own nixpkgs, Home Manager,
nix-darwin, and flake-parts inputs.

## Source and support

The release archive is built from the signed tag's commit. The accompanying
SHA-256 file and manifest identify the archive and source commit; the Sigstore
attestation covers the archive, checksum, notes, and manifest. Use the
verification commands in the release guide:

<https://github.com/nix-forge/nix-config-framework/blob/main/docs/releases.md>

This historical version is superseded by later versions. It receives no
backported fixes; see the current [support
policy](https://github.com/nix-forge/nix-config-framework/blob/main/SUPPORT.md)
before using it.
