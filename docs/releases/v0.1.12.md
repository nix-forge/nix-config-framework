# nix-config-framework v0.1.12

Historical source release for the signed [v0.1.12](https://github.com/nix-forge/nix-config-framework/tree/v0.1.12) tag. This note was written during the September 2026 release evidence backfill; it was not part of the original tagged tree.

## Changelog

### Functional changes

Ensured embedded Home Manager imports receive their home `system` and `configName` values; extended the integration fixture.

### Security changes

No security-specific change was recorded.

### Consumer impact and migration

Embedded Home Manager consumers whose modules need these arguments should update.
